# DriveNow – Сервис аренды автомобилей (Каршеринг)

Учебный проект по дисциплине «DevOps / Система управления версиями».

## Участники проекта
* Участник 1: Ахметов Даир
* Участник 2: Иус Максим

## Описание проекта
Веб-приложение для быстрых поездок по городу. 
Функционал включает просмотр доступных авто, выбор тарифа, интерактивный таймер поездки и расчёт стоимости аренды.

## Стек технологий
* React / Vite
* JavaScript
* CSS Modules / Inline styles
* Git / GitHub / GitLab CI / Jenkins

## Запуск проекта
1. Клонировать репозиторий
2. Установить зависимости: `npm install`
3. Запустить локально: `npm run dev`
